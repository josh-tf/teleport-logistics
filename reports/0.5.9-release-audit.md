# Teleporter 0.5.9 — release preparation audit

Prepared on 2026-09-15, branch `feature/player-teleporter`. Baseline: `46d13b5` (Relay 0.5.8). This is a local publication candidate, not a completed public launch.

## Outcome

The public name is **Teleporter**. The internal plugin reference, `/Script/Relay` classes, `/Relay` asset paths, saved properties and custom saved destination names are unchanged. Archive names retain Relay because they carry that plugin. Physical nameplates retain the earlier Relay branding; this is disclosed in the listing.

The publication kit is in [docs/publishing](../docs/publishing/README.md): prepared title/summary/full description, unlock and capacity tables, release notes, credits, icon, six transparent building captures and a 1600×900 banner. The banner uses actual asset renders and says “Model preview”; it is not presented as a game screenshot.

## Validation evidence

- **Portable checks:** seven production-scheduler scenarios, 60,000 randomized conservation steps under ASan/UBSan; source/model/material/connector/LOD checks passed. Six meshes, 150,470 full-detail triangles, 41 retained UE packages. LeakSanitizer disabled for the managed ptrace sandbox.
- **Archive regression tests:** five tests passed, including valid archives, unsafe paths, case collisions, symlinks, stale manifest metadata and missing required files.
- **Linux native editor:** CSS Unreal 5.6.1 build succeeded against the pinned CL502094 / SML 3.12.0 SDK.
- **Content inspector:** Unreal Python commandlet exited successfully. Checks include tiers/cost resources/quantities, native recipe products, holograms, material bindings, opaque detail hotfix, GC-safe stock reward presentation and distinct milestone symbols. Reconstructed SDK assets emit known warnings.
- **Native automation:** eight passed, zero failed/not-run; seven clean and one with SDK Blueprint warnings. [Machine-readable report](0.5.9-automation.json). Tests cover interaction lifecycle/snapshots, save/clipboard, endpoint/power visuals, forced-GC reward lifetime, Personnel contract/close.
- **Viewer:** offline Chromium passed all six models, surface modes, cameras, power/connection previews, keyboard controls and mobile overflow checks with no browser errors. [Versioned screenshots](model-renders/0.5.9/). Initial sandboxed Chromium launch was blocked by process restrictions; rerun with approved local browser execution passed.
- **Windows Shipping:** Steam/Epic client and Windows dedicated-server build/cook/stage succeeded (2m35s). Release assembler passed source/packaged manifest equality, required binaries/notices/containers, path checks and CRC checks. The combined archive is `dist/Relay-0.5.9.zip`; platform-specific archives are also available.

Raw execution logs were written under `/tmp/teleporter-059-*`; these are ephemeral. The automation report, summary and viewer captures are retained in the repository. Current screenshots validate model-viewer output only. Native game rendering/streaming is not reproduced by the SDK viewer.
