# Relay 0.4.8 rendering hotfix

The two uploaded logs are byte-identical and show Relay 0.4.7 failing to create a DirectX 12 graphics pipeline immediately after world load (HRESULT 80070057).

Both failed shaders map exclusively to `/Relay/Models/M_RelayDetails` in the 0.4.7 cooked SM6 shader archive:

- Vertex: `AA09756F9A5E65818F0DFB56A83405CB303AF2AB`
- Pixel: `5903D04B690C87FBFDA140AFCA01AF49AA369117`

The pipeline is depth-only (zero render targets). This establishes that the custom detail material participates in the failure; it does not establish the underlying compiler or driver defect.

## Change

Replace alpha-masked detail rendering with opaque printed plates. Texture alpha blends artwork over a dark base colour instead of clipping pixels. Labels and hazard markings remain, with dark backing in formerly transparent margins. No transport, save identity, UI, or mesh geometry changes.

The import pipeline uses the same material generator as the hotfix. Asset inspection rejects a masked detail material. The standalone generator should be run against a fresh material asset: this SDK asserts when deleting rooted expressions from a loaded material.

## Acceptance

The Linux headless editor cannot prove DirectX 12 rendering on the player's Windows GPU. Live acceptance requires loading the same save with 0.4.8, viewing Relay buildings, and confirming that world loading no longer crashes. Build and shader verification results are recorded in the accompanying validation report.
