# Relay 0.4.5: consistent flow arrows

All four endpoint screens use the same convention: Input points upward toward the item cube or fluid droplet; Output points downward away from it. Map icons use the same inward/outward vertical direction. The item cube and droplet are blue on inputs and orange on outputs, with shaded cube facets and a droplet highlight.

The former screen glyph drew a thick shaft up to the arrow's tip, underneath a separate triangular head. The shaft's width therefore protruded beside the point. Arrows are now single filled polygon outlines, with the shaft ending at the head's base. No overlapping line reaches the point.

The status dot is centred at x=256, matching the arrow and the midpoint of its x=160–352 line. The former ellipse was centred at x=251. Pixel checks confirmed the correction on all eight atlas tiles.

This is a texture/icon change. The 0.4.4 models, FICSIT identification plates, material slots, native connector transforms and runtime behavior are retained. Endpoint model-capture icons are refreshed to show the new screens.

See `model-renders/0.4.5/flow-arrows.png` for all four display glyphs. Final build/check results are recorded in `0.4.5-validation.txt`.
