# Relay 0.5.3 construction diagnostic

This is a diagnostic build, not a confirmed crash fix. It preserves 0.5.2 gameplay and assets and adds runtime actor-construction logging.

## Evidence

- The supplied 0.5.1 log confirms that version was loaded and hits the same `Widget_UseableBase_C:OnEscapePressed` to `SimpleConstructionScript` assertion as 0.5.2.
- The latest fresh-map bundle confirms Relay 0.5.2. Its stack reaches `AFGCharacterPlayer::SpawnEquipment` from player `BeginPlay`, then fails during construction. The older save-load stacks reached construction from save deserialization.
- The problem is therefore not confined to one saved world, and the 0.5.2 map integration is not required to reproduce the assertion.
- The supplied minidumps contain limited memory rather than full process memory. No offending actor class has yet been established.

## Instrumentation

Before `AActor::FinishSpawning`, the diagnostic logs the actor path and class under `LogRelayConstruction`, flushes the log, and writes `Relay.LastConstructingActor` and `Relay.LastConstructingClass` into the crash context. It leaves the native construction call unchanged. Instrumentation is disabled in the editor and commandlets.

The recorded class is the most recent construction entry, not automatically proof that this class caused corruption: nested construction or an earlier invalid reference may be responsible. Use the stack and log together.

## Test

Install the Windows diagnostic archive in place of the previous Relay version. Reproduce on a fresh map and return `FactoryGame.log` and `CrashContext.runtime-xml`. Logging every actor construction with a flush can slow loading; this build is for diagnosis.

A fresh-map test with Relay disabled and all other mods unchanged independently determines whether Relay is required to trigger the failure. No save editing or deletion is requested.

## Validation

- Linux FactoryEditor build succeeded (`/tmp/relay-053-editor.log`).
- Windows Steam, Epic and dedicated-server Shipping packaging succeeded, AutomationTool exit code 0 (`/tmp/relay-053-package.log`).
- Source/content validation passed (`/tmp/relay-053-validate.log`).
- The runtime hook has not been exercised inside the retail game here. A new user reproduction is still required; no crash fix is claimed.
