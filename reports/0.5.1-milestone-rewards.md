# Relay 0.5.1 — native milestone rewards

Both Relay Logistics (Tier 5) and Relay Personnel Transport (Tier 9) used native `UFGUnlockRecipe` subclasses. They grant recipes but do not implement the stock Blueprint `BPI_UnlockableInterface`, including `GetUnlockRewardWidgets`. This explains why counting recipes in the earlier SDK inspections did not catch the blank native Rewards panel.

Both milestones now instantiate the game-owned `BP_UnlockRecipe` wrapper and populate its recipe array with the same five logistics recipes or one Personnel recipe. Native schematic classes, recipe classes, saved identifiers, unlock tiers and resource costs remain unchanged. No model/material changes are included.

The new inspection checks the actual unlock object implements the stock reward interface, as well as checking its class, recipe counts, costs and icons. The stock wrapper is also the approach shown in the [SML recipe and schematic tutorial](https://docs.ficsit.app/satisfactory-modding/latest/Development/BeginnersGuide/SimpleMod/recipe.html).

The submitted screenshot marks the milestone as purchased. Its blank remaining-cost section is not sufficient evidence that configured costs are missing. Inspection confirms Tier 5 costs of 100 Circuit Boards, 100 Reinforced Iron Plates and 200 Cable; Tier 9 costs remain 200 Time Crystals, 100 Supercomputers and 50 Turbo Motors.

Validation: native editor compilation passed; both milestones pass reward-interface inspection; seven native automation tests passed (one existing test has reconstructed-SDK Blueprint warnings); transport conservation and content/model checks passed. Native game reward rendering must still be checked after installing 0.5.1 because reconstructed Blueprint graphs cannot reproduce the shipped game UI.

Install the complete 0.5.1 Windows plugin in place of 0.5.0. Use the matching WindowsServer archive on dedicated servers. Reopen the HUB milestone page and verify five logistics rewards and one Personnel Relay reward, including already-purchased milestones. Verify resource costs on a save where the milestone has not yet been purchased.
