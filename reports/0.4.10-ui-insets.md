# Relay 0.4.10 panel insets

The live screenshots show the route helper text on the SFUIKIT bottom bevel, with the route field close to the bevel boundary. The old 16-unit content inset did not account for the artwork's decorative edge.

All main plates now reserve 20 units at the top/sides and 32 at the bottom. The route editor uses a short label and an explanatory placeholder; its redundant bottom helper is a tooltip, so it cannot overlap the bevel. No outer scrolling, model/material changes, or runtime transport changes.

Validation uses the existing native interaction/layout suite. Actual raster appearance remains an in-game Windows check; this VM's Vulkan renderer cannot capture the editor UI.
