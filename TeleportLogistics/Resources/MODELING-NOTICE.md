# Satisfactory Modeling Tools connector meshes

TeleportLogistics uses the following original, community-created connector meshes from
[David "AngryBeaver" Gillen's Satisfactory Modeling Tools](https://github.com/DavidHGillen/Satisfactory_ModelingTools):

- `FactoryBelt_In`
- `FactoryBelt_Out`
- `FactoryPipe_In`
- `FactoryPipe_Out`
- `PowerConnector_Compact`

Upstream grants use in its README, verbatim:

"This content was built from scratch by referencing assets ripped from the game and is ONLY for free use
with Satisfactory mods, memes, videos, content, reviews, etc. Any other use (paid or otherwise) is against
my and probably the developers desires and will be terminated."

That is a custom permission, not a standard licence, and these meshes are not covered by this mod's MIT licence. These pieces
are used only in the TeleportLogistics Satisfactory mod. The source snapshot was retrieved
from the upstream repository on 2026-09-13.

All remaining TeleportLogistics model geometry is original to TeleportLogistics.
