# Teleport Logistics

**Connect distant factories. Travel between your outposts.**

Build an input and an output, give them the same named route, and connect your belts or pipes. Cargo crosses the map with no train line, truck path or drone port in between. Late game, your Pioneer can travel the same network.

## What you get

<a href="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=2%2F10++What+you+get%0AAll+six+buildings%2C+powered&slot=IMG_BUILDINGS"><img alt="The six Teleport Logistics buildings placed side by side" src="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=2%2F10++What+you+get%0AAll+six+buildings%2C+powered&slot=IMG_BUILDINGS" width="480"></a>

- **Item Teleporters:** send mixed conveyor cargo between factories. Multiple inputs merge, and multiple outputs share available supply.
- **Fluid Teleporters:** move liquids or gases through routes that keep different fluid types separate.
- **Teleporter Hubs:** optional. Group routes into named channels and manage a large network from one window.
- **Personnel Teleporters:** choose a powered destination from a searchable directory, with coordinates and optional native sign icons.
- Six industrial buildings with Customizer support, directional indicators and map entries. Logistics and Personnel use separate map sections.

Full building reference: [Buildings](https://github.com/josh-tf/teleport-logistics/wiki/Buildings)

## Your first route

1. Build an Input and an Output.
2. Press **E** on each. Keep the **Default** channel, enter the same route name, and apply.
3. Feed the Input with a belt or pipe and connect the Output to your factory.

<a href="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=5%2F10++Your+first+route%0AEndpoint+window%2C+buffer&slot=IMG_ENDPOINT_UI"><img alt="Endpoint window showing label, channel, route and the local item buffer" src="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=5%2F10++Your+first+route%0AEndpoint+window%2C+buffer&slot=IMG_ENDPOINT_UI" width="480"></a>

**Input** sends cargo into the network. **Output** brings it back out. Each endpoint holds a small local buffer you can watch while a route fills.

Step-by-step with screenshots: [Your first route](https://github.com/josh-tf/teleport-logistics/wiki/First-Route)

### Channels and routes

Default works without a hub. A powered management hub gives you a separate named channel; logistics continue when that hub loses power.

<a href="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=6%2F10++Channels+and+routes%0ARoute+picker%2C+search&slot=IMG_CHANNEL_SELECT"><img alt="Channel and route picker with search and the create-a-route option" src="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=6%2F10++Channels+and+routes%0ARoute+picker%2C+search&slot=IMG_CHANNEL_SELECT" width="480"></a>

More on naming, searching and reassigning: [Channels and routes](https://github.com/josh-tf/teleport-logistics/wiki/Channels-and-Routes)

### Fluids

Fluid routes keep each fluid type separate and expose the local buffer. Flushing is explicit and discards the local buffer only. Your pipe network is untouched.

<a href="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=7%2F10++Fluids%0APipes%2C+fluid+buffer+open&slot=IMG_FLUID_ROUTE"><img alt="Fluid Input and Output connected by pipes with the endpoint buffer open" src="https://placehold.co/1600x900/1b1b1b/e9e9e9/png?text=7%2F10++Fluids%0APipes%2C+fluid+buffer+open&slot=IMG_FLUID_ROUTE" width="480"></a>

### Hubs

A hub is optional. Use one to group routes into a named channel, search a large network, read endpoint coordinates and buffers, and rename or pause routes from one window.

### Personal travel

Build and power two Personnel Teleporters. Name them, then press E and click a ready destination. The placement arrow marks the front exit. Busy or blocked destinations cannot accept travel.

## Power and capacity

| Building | Power | Capacity |
| --- | --- | --- |
| Item endpoint | None | 64 items; up to 1,200 items/min |
| Fluid endpoint | None | 50 m³; up to 600 m³/min |
| Management hub | 5 MW | No cargo storage |
| Personnel Teleporter | 50 MW at each end | 30-second hub reservation per journey |

Throughput limits apply per endpoint and are further limited by connected belts/pipes, supply and receiving capacity. They are configured ceilings, not guaranteed measured rates. The network supports up to 256 routes. Drain local buffers before reassigning routes.

[Throughput and power in detail](https://github.com/josh-tf/teleport-logistics/wiki/Throughput-and-Power)

## Compatibility

Built for Satisfactory CL502094 with SML 3.12.0. Install the same mod version on host and clients. Windows Steam/Epic client and Windows dedicated-server packages are included. Linux dedicated-server and controller support are not currently certified.

This is a pre-1.0 candidate. Final retail-game multiplayer, progression and save/reload acceptance is still being completed. Keep a backup of test saves.
